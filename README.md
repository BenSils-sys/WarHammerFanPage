# Warhammer 40K Fan Website

A multi-page fan site for Warhammer 40,000 built with HTML, Bootstrap 5, CSS, JavaScript, and PHP.

## Live Site
[View on GitHub Pages](https://bensils-sys.github.io/WarHammerFanPage/)

## How to Run PHP Locally

1. Install XAMPP from https://www.apachefriends.org/
2. Copy the WarHammer folder into C:/xampp/htdocs/
3. Start Apache in the XAMPP Control Panel
4. Open http://localhost/WarHammer/index.html in your browser
